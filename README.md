# 写真カレンダー

撮影日ごとに選んだ写真と、その日のタイトル・メモをカレンダーで見返すためのアプリです。PCとAndroidの両方のブラウザで動きます。

- データの保存先は自分のGoogleドライブの `PhotoCalendar` フォルダです。
  - `photos/`: 写真（長辺2048px）
  - `thumbs/`: サムネイル
  - `index.json`: タイトル・メモ・写真の並び
- 一度表示した写真は端末内に保存されるため、オフラインでも見られます。
- サーバーは不要です。静的ファイルを置くだけで動きます（ここではGitHub Pagesを使います）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML/CSS/JSすべて） |
| `sw.js` | オフライン用のサービスワーカー |
| `manifest.webmanifest`, `icon*.png`, `icon.svg` | ホーム画面に追加するためのファイル |

## セットアップ（最初の1回だけ、30分ほど）

### 1. GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作ります（例：`photo-calendar`）。Publicで構いません。中身はアプリのコードだけで、写真は含みません。
2. このフォルダのファイルをすべてアップロードします。
3. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存します。
4. 数分後に `https://<GitHubユーザー名>.github.io/photo-calendar/` で開けるようになります。

### 2. GoogleのクライアントIDを作る

1. <https://console.cloud.google.com/> を開き、新しいプロジェクトを作ります（例：`photo-calendar`）。
2. **APIとサービス → ライブラリ** で「Google Drive API」を検索し、**有効にする**を押します。
3. **Google Auth Platform（OAuth同意画面）** を設定します。
   - アプリ名：写真カレンダー（任意）
   - ユーザーの種類：**外部**
   - サポートメール：自分のGmail
   - **対象（テストユーザー）** に自分のGmailアドレスを追加します。
   - 公開ステータスは「テスト中」のままで構いません。
4. **クライアント → クライアントを作成** を開きます。
   - アプリケーションの種類：**ウェブ アプリケーション**
   - **承認済みの JavaScript 生成元** に次を追加します（パスは付けません）。
     - `https://<GitHubユーザー名>.github.io`
     - PCでローカル確認もしたい場合は `http://localhost:8000`
   - 承認済みのリダイレクトURIは不要です。
5. 作成後に表示される **クライアントID**（`….apps.googleusercontent.com`）をコピーします。

使う権限は `drive.file` だけです。このアプリが作ったファイルにしかアクセスできないので、ドライブにある他のファイルは読まれません。

### 3. アプリで設定する

1. 公開したURLを開き、右上の「未設定」をタップして設定画面を開きます。
2. クライアントIDを貼り付けて **保存** します。
3. **ログイン** を押し、自分のアカウントを選んで許可します。
   - 「このアプリは Google で確認されていません」と表示されたら、**詳細 → 写真カレンダー（安全ではないページ）に移動** を選びます。自分で作ったアプリなので問題ありません。
4. PCとスマホの両方で、同じように設定とログインをします。クライアントIDの登録は端末ごとに1回だけです。

### 4. Androidのホーム画面に追加する

Chromeでアプリを開き、メニュー（︙）から **ホーム画面に追加**（または「アプリをインストール」）を選びます。

## 使い方

- **写真を追加**：Androidの写真ピッカーで写真を選ぶと、アプリ内の確認画面が開きます。撮影日ごとに並んでいるので、タップして拡大（ピンチ可）しながら残す写真を選び、「追加」を押します。撮影日（EXIF → ファイル名 → 更新日時の順に判定）のマスに自動で入ります。
- **日付をタップ**：タイトル（例：運動会）とメモを入力できます。入力は自動で保存されます。
- **写真をタップ**：拡大表示します。スワイプで前後の写真へ移動し、「表紙にする」でカレンダーに出る写真を変えられます。
- **共有**：拡大表示の「共有」で1枚、日付画面の「写真を共有」で複数枚を、LINEなどに送れます（スマホの共有メニューが開きます）。
- **設定**：右上の ⚙ から開きます。クライアントID、写真の保存サイズ、同期、キャッシュの設定があります。
- **イベント一覧**：タイトルやメモで検索できます。
- カレンダーは左右スワイプで月を移動できます。
- **拡大**：写真はピンチ操作かダブルタップで拡大できます（最大6倍）。PCではマウスホイールで拡大し、ドラッグで動かします。拡大していないときは左右スワイプで前後の写真に移動します。
- **保存サイズ**：設定画面で、これから追加する写真の長辺を2048px（標準）、3072px、4096pxから選べます。

### 同期について

- ログインの有効期限は約1時間です。期限が切れたら、もう一度「ログイン」を押してください（2回目以降は確認画面がほぼ出ません）。
- タイトルやメモはオフラインでも編集でき、次にログインしたときにドライブへ同期されます。
- 写真の追加にはログインとネット接続が必要です。
- 2台で同じ日を同時に編集した場合、タイトル・メモは後から保存した方が残ります。写真は両方の追加分がまとめて残ります。

### 制限

- HEIC形式は読み込めません。カメラの設定で保存形式をJPEGにしてください（Pixelなど多くのAndroid端末は標準でJPEGです）。
- 保存される写真は、設定した保存サイズ（標準は長辺2048px）に縮小されます。元の写真はGoogleフォトなどに残しておいてください。
- 写真を削除すると、ドライブの元ファイルはゴミ箱に移動します（30日間は復元できます）。

## ローカルで試す（PC）

```bash
cd photo-calendar
python -m http.server 8000
# http://localhost:8000 を開く（クライアントIDの生成元に http://localhost:8000 の登録が必要）
```
